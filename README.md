# Tile World, L.C. – Ceramic & Marble Flooring Website

This website was built as a clean and mobile-friendly landing page for **Tile World, L.C.**, a local Maryland business specializing in ceramic/marble flooring.  
It’s a simple website made with HTML and CSS, designed to portray the company’s services, contact information, and its impact with an efficient/user-friendly navigational system.

## Features

### A warm, professional design
The site uses a flooring-inspired color palette, clean typography, and subtle shadows to create a trustworthy, inviting feel. Everything is tuned to look great on both desktop and mobile devices.

### Simple, intuitive navigation
Users can move through sections with smooth scrolling and a sticky header. An access friendly “Skip to Content” link is included for better usability.

### Clear presentation of services
The website highlights the core services the business offers:
- Ceramic tile installation  
- Marble flooring  
- Repair and replacement work  

### Project gallery
A tile-style gallery section is included for showcasing completed projects. Replace the placeholders with real images when you're ready.

### Contact & estimate request form
A simple form allows visitors to send their name, email, phone number, and details about their flooring project.  
*(This version is a demo form — no backend required.)*

### Optimized for mobile
Built with CSS Grid and Flexbox, the layout adapts smoothly to any screen size, making the site easy to browse on phones, tablets, and laptops.
